プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-22

オグリメディア（以下「当社」）が運用する社内ツール「オグリ自動化ハブ」（以下「本ツール」）における、 Google アカウントおよび YouTube のデータの取り扱いを定めます。本ツールは YouTube API Services を使用しています。

1. 利用する情報

本ツールは、当社が管理する YouTube チャンネルについて、YouTube API Services を通じて次の情報を利用します。

  • チャンネル名・チャンネル ID・登録者数などのチャンネル情報
  • 動画のアップロード・予約公開に必要な情報（動画ファイル・タイトル・説明・タグ・公開日時）と、アップロードした動画の公開状態
  • 当社が公開した動画への、チャンネルとしてのコメントの投稿
  • YouTube Analytics の集計データ（再生数・視聴時間・視聴者維持率・登録者の増減）

本ツールは、当社以外の方の Google アカウントにログインしたり、その方の非公開データを取得したりすることはありません。

2. 利用目的

当社が制作した動画を当社チャンネルへ投稿・予約公開すること、当社の動画にお知らせのコメントを投稿すること、 および当社チャンネルの成績を社内で確認することにのみ利用します。広告や第三者への提供には利用しません。

3. 保存・共有・削除

  • 認証情報（アクセストークン等）と取得したデータは、当社が管理するコンピューター内にのみ保存します。
  • 取得したデータを第三者に提供・販売・共有することはありません。
  • YouTube API Services から取得したデータは、30日を超えて古いまま保存せず、30日以内に更新するか削除します。
  • アクセスが取り消された場合、または連携を解除した場合は、そのアカウントの認証情報と取得したデータを7日以内に削除します。
  • 削除のご依頼は、下記のお問い合わせ先までご連絡ください。

4. アクセスの取り消し

Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」 （https://myaccount.google.com/connections）から、 いつでも本ツールへのアクセスを取り消せます。

5. YouTube API Services

本ツールは YouTube API Services を使用しています。本ツールの利用には YouTube 利用規約 および Google プライバシーポリシー が適用されます。

English

This Privacy Policy describes how Oguri Media ("we") handles Google account and YouTube data in its internal tool "Oguri Automation Hub" (the "Tool"). The Tool uses YouTube API Services.

1. Information we use

For the YouTube channels that we own and manage, the Tool uses the following through YouTube API Services:

  • Channel information such as channel name, channel ID and subscriber count
  • Information needed to upload and schedule our videos (video file, title, description, tags, publish time) and the privacy status of the uploaded videos
  • Posting a comment as the channel on videos that we published
  • Aggregated YouTube Analytics data (views, watch time, audience retention, subscriber changes)

The Tool never signs in to, or retrieves private data from, any Google account other than our own.

2. How we use it

Only to upload and schedule videos we produced to our own channels, to post announcement comments on our own videos, and to review our own channels' performance internally. We do not use the data for advertising and do not provide it to third parties.

3. Storage, sharing and deletion

  • Authorization data (such as access tokens) and retrieved data are stored only on computers managed by us.
  • We do not sell, share or disclose the data to any third party.
  • Data obtained from YouTube API Services is refreshed or deleted within 30 days and is not kept stale beyond that.
  • If access is revoked or an account is disconnected, its authorization data and retrieved data are deleted within 7 days.
  • To request deletion, contact us at the address below.

4. Revoking access

You can revoke the Tool's access at any time from your Google Account's security settings: https://myaccount.google.com/connections.

5. YouTube API Services

The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service, and the Google Privacy Policy applies.
